# Decisions and constraints

## 2026-11-13 — Working name, not brand commitment

- Interface uses **Jinn** as an internal persona / codename.
- Brand/product name undecided: candidates include Wisht, Wish & Done, Deedly, Wishcraft, Three Deeds. No legal/domain clearance performed.
- Repo and code deliberately permit renaming.

## 2026-11-13 — Ship first experience before cloud

- Build local React/Vite frontend and Node/TS API with no credentials.
- User will organize GitHub repo; bundle is Git-ready.
- Only after JINN-001 acceptance, configure Netlify + Railway, then Supabase when real persistence is required.
- Avoid Docker, ORM, agent framework, paid APIs and heavyweight UI systems at this stage.

## 2026-11-13 — Bounded deterministic routing for initial story

- JINN-001 recognizes explicit patterns and refuses to promise unsupported actions.
- No LLM required for a UX prototype; a provider-neutral semantic router can replace it when measured coverage warrants.
- Rule-based detection is deliberately limited and not a claim to understand every aspiration.

## 2026-11-13 — Three wishes are future execution entitlements

- For now show three available wishes as an experience motif only; no consumption ledger.
- Define quotas and payment only after actual mission economics are observed.

## 2026-11-13 — No fake success and no sensitive shadow profiling

- A mission plan is marked **NOT EXECUTED**.
- No external publication, messaging or hidden profile matching.
- For sensitive personal aspirations, default to privacy-first, discreet behaviour.
